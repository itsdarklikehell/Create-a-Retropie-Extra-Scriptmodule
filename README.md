A scriptkiddies way of creating unofficial installation scripts for RetroPie or Exarkuniv's Retropie-Extra — allowing you to quickly and easily create installation scripts for emulators, ports, libretrocores or anything you can run that haven't been added yet.

## Installatie

### Vereisten

- RetroPie of RetroPie-Extra geïnstalleerd
- Basiskennis van bash scripting

### Installatie

```bash
git clone https://github.com/itsdarklikehell/Create-a-Retropie-Extra-Scriptmodule.git
cd Create-a-Retropie-Extra-Scriptmodule
```

## Gebruik

```bash
# Maak een nieuw script
cp template.sh my-new-script.sh
# Bewerk het script
nano my-new-script.sh
# Test het script
bash my-new-script.sh
```
